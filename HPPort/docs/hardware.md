# Hardware Notes

## Minimum Setup

- Raspberry Pi 5
- Raspberry Pi OS
- Camera
- Microphone
- Speaker

## Recommended Setup

- Raspberry Pi Camera Module 3
- Hailo AI HAT with a person-detection `.hef`
- Powered USB microphone
- Small amplified speaker behind the frame
- 7-10 inch HDMI display

## Tuning Areas

- Camera angle should catch approach before the visitor reaches the frame.
- Microphone placement matters more than model tuning for usable conversation.
- Speaker volume should not be high enough to retrigger STT.
